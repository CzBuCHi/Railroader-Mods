# Teleporter 2.0.5

Requires RTM.RailForge. Mod ID: CzBuCHi.Teleporter.

Open the portal toolbar icon. Select or name a group, enter a location name, and click Save current. Click a saved location's destination icon to return. Copy replaces a location, × deletes it, and both require confirmation. Arrows reorder groups.

First-person positions restore character location and viewing direction. Tracking-camera positions restore location, orientation, and zoom. Saved coordinates are absolute. Native Loading appears only when destination loading takes long enough.

Compatible groups and locations are retained under the original mod ID. Data is saved immediately and shared between maps. The window is movable and resizable; settings can open it after map loading.

Close the game and extract Mods/CzBuCHi.Teleporter into its game directory. Keep only one installed version.

Build from the repository root with dotnet publish Teleporter/Teleporter.csproj -c Release. The ZIP is created in the repository bin directory. The release package includes the detailed guide at docs/Teleporter.md.
