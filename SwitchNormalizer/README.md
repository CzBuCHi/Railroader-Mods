# SwitchNormalizer 2.0.4

Requires RTM.RailForge. Mod ID: CzBuCHi.SwitchNormalizer.

Click the switch icon in the top toolbar to restore saved switch positions. Shift-click to save the current positions. Without a profile, eligible switches default to isThrown = false. The profile is shared between maps.

Restoration respects native permissions and locked CTC switches. Compatible RailForge legacy settings remain usable; separate standalone Railloader settings are not automatically imported.

Close the game and extract Mods/CzBuCHi.SwitchNormalizer into its game directory. Keep only one installed version.

Build from the repository root with dotnet publish SwitchNormalizer/SwitchNormalizer.csproj -c Release. The ZIP is created in the repository bin directory. The release package includes the detailed guide at docs/SwitchNormalizer.md.
